# 电子签服务商与法律效力核验清单

> **适用范围**：仅在 `ESIGN_ENABLED=true`、启用第三方可靠电子签时适用。
> 默认关闭时验收使用手写签名，它只是项目内部确认记录，**不具备法律效力**。
>
> 本文不是法律意见。代码只能保证“技术链路正确”，不能单独保证法律效力；
> 上线前请让律师审阅验收文本、同意书、隐私政策与服务商合同。

## 1. 服务商资质

- [ ] 电子认证服务许可证 / CA 合作或自有 CA 资质
- [ ] 可信时间戳服务（TSA）与时间源说明
- [ ] PDF 数字签名格式（PAdES）与长期验证（LTV）能力
- [ ] 验签 API 能返回原始文档哈希、证书序列号、签署时间
- [ ] 证据报告内容：实名信息、证书信息、签署过程、哈希、时间戳、存证情况
- [ ] 司法存证/公证/鉴定/仲裁合作情况（按业务需要）
- [ ] 等保、ISO 27001 等安全资质
- [ ] 数据境内存储、子处理者清单、PIPL 数据处理协议
- [ ] SLA、回调重试策略、限流、SDK/API 版本策略

## 2. 实名与意愿

- [ ] 个人身份证实名 + 人脸活体核验
- [ ] 每次签署的意愿认证（短信/人脸/密码）
- [ ] 服务商返回的实名主体 id 可稳定绑定到本地用户
- [ ] 姓名/证件号/人脸不在本地落库；日志脱敏
- [ ] 小程序内第三方人脸核身的微信审核政策已确认

## 3. 签署文件

- [ ] 验收确认书文本经律师审阅：验收范围、结论、双方主体、日期、争议解决
- [ ] 单方确认书/单签署人流程被服务商支持
- [ ] 签署前 PDF 冻结，签署后 PDF 与原文件哈希可验证
- [ ] 缺照片/字体/分页时拒绝签署，不生成“照片加载失败”的法律文件
- [ ] 证据报告/已签 PDF 的保留年限、删除与法律保留策略

## 4. 技术与运维

- [ ] `ESIGN_*` 凭据只存在 600 权限的 `.env`，不提交、不回显
- [ ] 回调 URL 为 HTTPS，已加入服务商白名单
- [ ] 回调密钥支持轮换（当前 + 上一把）
- [ ] 私有存储独立于 `/uploads`，有加密/版本/异地备份
- [ ] 回调/查单/归档/失败告警接入监控
- [ ] 服务商故障时有 `ESIGN_SIGNING_PAUSED` 流程，不回退手写签名

## 5. 仍需业务确认

- 主业主实名信息是否要与项目业主姓名做一致性校验（当前只绑定登录账号+手机号+服务商实名）
- 是否需要公司章/装修公司作为第二签署方
- 证据报告/已签 PDF 的对外提供与转发规则
- 线下签署/纸质签署的例外流程
